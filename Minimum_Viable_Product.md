
# Minimum Viable Product Features

## 1. Resale/Rental Platform

### Item Listing System
- **Price Setting**
  - User-defined pricing with suggested ranges (10-15% retail value)
  - Price based on:
    - Item condition (New/Excellent/Good)
    - Brand prestige factor
    - Seasonal demand

- **Rental Duration Options**
  - Short-term (3-7 days) for events
  - Medium-term (2-4 weeks) for vacations
  - Long-term (1+ months) for workwear

### Request Management
- **Google Forms Integration**
  - Standardized request fields:
    - Item ID reference
    - Requested dates
    - Special requirements
  - Auto-generated confirmation emails

- **Manual Matching Process**
  - Dedicated operations team (4-person initial staff)
  - Matching criteria:
    - Location proximity (<5mi preferred)
    - Size compatibility
    - Rental history ratings

## 2. Fast Fashion Impact Awareness

### Environmental Cost Dashboard
- **Brand Impact Visualization**
  - CO₂ emissions (kg per garment)
  - Water usage (liters) with river basin comparisons
  - Microplastic pollution estimates

- **Behavioral Survey Module**
  - Pre-exposure questions:
    "How often do you consider environmental impact when shopping?"
  - Post-exposure measurement:
    "Does this information change your purchase intent?"

## 3. Recycling Drop-off Service

### Location Finder
- **Zip Code Processing**
  - Radius search (3/5/10 mile options)
  - Accessibility filters:
    - Public transport access
    - Disability access
    - Parking availability

- **Manual Response System**
  - Curated location recommendations:
    1. Charity shops
    2. Textile banks
    3. Repair centers
  - Typical response time: <90 minutes

## 4. Clothing Pickup Program

### Scheduled Collections
- **Monthly Pickup System**
  - Calendar integration (Google)
  - Preparation reminders:
    - "Your pickup is tomorrow - have items bagged by 8am"
  - Real-time tracking:
    - 2-hour arrival windows
    - Driver GPS updates

## 5. Thrift E-Commerce Platform

### Product Presentation
- **Model Showcase**
  - Diverse body types (8 standard sizes)
  - Fabric close-ups with zoom

- **Educational Content**
  - "This purchase saves 3,200L water"
  - "Previous owner's care tips"
  - Brand sustainability report cards
